# ✍️ Arquivo Fonte do Livro (DOCX)

Esta pasta contém o arquivo fonte editável do livro **"Wazuh: Guia de Implementação Estruturada e Monitoramento Multiplataforma"** em formato `.docx`.

O objetivo desta pasta é permitir que a comunidade e outros profissionais de Cibersegurança possam sugerir correções de texto, revisões gramaticais, melhorias em comandos ou novos conteúdos.

---

## 📁 Arquivo Disponível

- **`Manual-Wazuh-PT.docx`**: Arquivo editável completo do manual.

---

## 🤝 Como Sugerir Correções ou Melhorias

Se você encontrou algum erro, quer melhorar a explicação de um capítulo ou sugerir novas seções para o livro:

1. **Faça um Fork** deste repositório.
2. Baixe o arquivo `.docx` localizado nesta pasta.
3. Faça as correções ou adições diretamente no documento (utilize a opção de *Controlar Alterações / Track Changes* do Word/Office, se possível).
4. Faça o upload do arquivo atualizado para a sua branch na pasta `source/`.
5. Abra um **Pull Request** descrevendo brevemente quais correções ou melhorias foram realizadas.

Sua contribuição é muito bem-vinda para manter este guia sempre atualizado e preciso!
